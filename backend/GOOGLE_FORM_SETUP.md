# Google Form to MongoDB setup

Your candidate form link is:

```text
https://docs.google.com/forms/d/e/1FAIpQLSfP7dBdZ8pN1R6JRNAjPaMJdi8PGvTyY3WXNm0MGjKeFYAeng/viewform?usp=sharing&ouid=102653775178829573465
```

Send this link to candidates only after the form is connected to a Google Sheet and the Apps Script trigger is added.

## Backend

Add this value to `backend/.env`:

```env
GOOGLE_FORM_WEBHOOK_SECRET=choose-a-long-random-secret
```

Deploy/start the backend, then use this API URL in Apps Script:

```text
https://your-backend-domain.com/api/candidates/google-form
```

For local backend testing only, use:

```text
http://localhost:5000/api/candidates/google-form
```

Google Apps Script cannot call `localhost`, so real Google Form submissions need a deployed backend URL.

## Google Sheet Apps Script

In the Google Sheet connected to the form, open `Extensions > Apps Script` and paste:

```javascript
const BACKEND_URL = "https://your-backend-domain.com/api/candidates/google-form";
const WEBHOOK_SECRET = "same-secret-as-backend-env";

function onFormSubmit(e) {
  const values = e.namedValues;

  const getValue = (possibleNames) => {
    for (const name of possibleNames) {
      if (values[name] && values[name][0]) {
        return values[name][0];
      }
    }
    return "";
  };

  const payload = {
    name: getValue(["Name", "Full Name"]),
    email: getValue(["Email", "Email Address"]),
    phone: getValue(["Phone Number", "Phone No", "Phone no", "Mobile Number"]),
    address: getValue(["Address"]),
    resume: getValue(["Resume", "Resume Link", "CV", "CV Link"]),
    about: getValue(["About Yourself", "Overall about yourself", "Overall About Yourself", "About"])
  };

  UrlFetchApp.fetch(BACKEND_URL, {
    method: "post",
    contentType: "application/json",
    headers: {
      "x-google-form-secret": WEBHOOK_SECRET
    },
    payload: JSON.stringify(payload),
    muteHttpExceptions: true
  });
}
```

Then create the trigger:

1. Click `Triggers`.
2. Add a trigger for `onFormSubmit`.
3. Event source: `From spreadsheet`.
4. Event type: `On form submit`.

The backend validates name and email, then saves or updates the candidate in MongoDB by email.
